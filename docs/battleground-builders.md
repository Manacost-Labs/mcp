# Battlegrounds images

`render_battlegrounds_strategy` и `render_battlegrounds_tier_list` возвращают
нативный MCP image block (`image/png`) и небольшой JSON с размерами, количеством
карт и ссылками на каталог. Совместимый клиент может показать картинку в чате.
Файлы, пользовательские черновики и публикации на HearthPulse не создаются.
Доступ сохраняет существующий OAuth и действующую роль администратора.

## Карты

Сначала вызовите `search_cards` с `mode: "battlegrounds"`. Поле `source` выбирает
`card`, `hero` или `trinket`; результат содержит настоящий `card_id`. Для героев
и карт доступен `query`. Аксессуары перечисляются по `page`/`perPage` без `query`:
текстовый фильтр этого upstream сейчас возвращает ошибку. Передавайте найденный
ID как `cardId` и тот же `source` в рендерер. Не придумывайте ID или изображения.

## Стратегия

`rows` — 1–10, по умолчанию последний занятый ряд; пять колонок фиксированы.
Карты занимают уникальные ячейки `row`/`column` (нумерация с единицы), имеют
уникальный `key`, опциональные `note` и `highlighted`. `showGrid` по умолчанию true.
До 50 карт, заголовок до 100 символов, заметка до 80 символов.

```json
{
  "title": "Пример стратегии",
  "rows": 2,
  "cards": [
    {"key": "first", "cardId": "BG28_897", "row": 1, "column": 1}
  ],
  "annotations": [{"type": "label", "from": "first", "text": "Начало"}]
}
```

До 100 аннотаций: `arrow`, `double-arrow`, `plus`, `equals` связывают `from` и `to`;
`question`, `strike`, `label` относятся к `from`. Ссылки используют `key` карт.
Для `label` обязателен текст. Названия карт и заметки экранируются как текст.

## Тир-лист

`tiers` содержит уникальные S/A/B/C/D в выбранном порядке. Каждый ряд имеет
опциональный `label` и `cards` с `cardId`, `source`, `note`, `highlighted`.
`columns` — 1–10, по умолчанию 5. Всего 1–100 карт, до 50 в одном тире.
Одна карта каталога может находиться только в одном тире.

```json
{
  "title": "Пример тир-листа",
  "columns": 5,
  "tiers": [
    {"tier": "S", "cards": [{"cardId": "TB_BaconShop_HERO_16", "source": "hero"}]},
    {"tier": "A", "cards": []}
  ]
}
```

Это пример размещения, а не рекомендация силы героя. Рендерер не получает
статистику автоматически: AI должен отдельно найти актуальные данные.

## Ограничения и проверки

Ширина PNG — 1600 пикселей; высота зависит от рядов. До 16 миллионов пикселей,
8 MiB PNG, двух одновременных генераций и 60 секунд на загрузку исходников.
При слишком высоком тир-листе увеличьте `columns`. Изображения загружаются только
с разрешённых каталогом доменов, без передачи им credentials. Произвольные URL,
SVG и локальные файлы не принимаются. Ошибка карты/изображения отменяет всю
генерацию, сохраняя явный код ошибки вместо неполной картинки.

Проверки: `npm run check`, `npm audit --omit=dev --audit-level=high`.
`tests/builders.test.ts` проверяет ограничения, PNG, геометрию и опасные URL;
`tests/mcp.test.ts` — OAuth, discovery и настоящие image blocks обоих инструментов.

Для ChatGPT используйте существующий remote MCP `https://hearthpulse.net/mcp`
по [инструкции клиента](clients.md). После обновления сервера обновите список
инструментов приложения в клиенте. Проверка своего входа и отображения в ChatGPT
выполняется владельцем аккаунта; серверные тесты не подтверждают состояние его чата.
